### Sobre o projeto

Este é meu portfólio pessoal, desenvolvido para reunir em um único lugar um pouco sobre mim, meus conhecimentos, projetos acadêmicos e experiências com programação e eletrônica.

Sou Rafael Montenegro Ribeiro, estudante de Engenharia da Computação na Universidade São Francisco (USF), em Bragança Paulista. Gosto de aprender colocando a mão na massa, desenvolvendo projetos e explorando diferentes áreas da tecnologia.

O objetivo do site é apresentar minha evolução acadêmica e profissional, além de compartilhar os projetos que venho desenvolvendo ao longo dessa jornada.

## Funcionalidades

- **Apresentação pessoal:** informações sobre minha formação, trajetória e interesses.
- **Projetos:** apresentação dos meus projetos acadêmicos e pessoais, com links para seus respectivos repositórios.
- **Habilidades:** tecnologias, ferramentas e conhecimentos que venho desenvolvendo.
- **Idiomas:** alternância entre português e inglês.
- **Tema claro e escuro:** possibilidade de personalizar a aparência do site.
- **Gostos pessoais:** uma seção dedicada aos meus interesses fora da tecnologia.
- **Currículo:** visualização e download do meu currículo em PDF.
- **Terminal interativo:** uma seção com comandos que apresentam informações sobre mim e meus projetos.
- **Formulário de contato:** permite que visitantes enviem mensagens diretamente para meu e-mail.
- **Design responsivo:** adaptação para diferentes tamanhos de tela.

## Projetos em destaque

### 01. Sistema de Controle de Acesso — NFC/RFID

Protótipo desenvolvido para a Feira de Projetos da USF de 2026. Utiliza o módulo RFID-RC522 para identificar cartões e verificar permissões de acesso, acionando LEDs, buzzer e um servo motor que simula a abertura de uma porta.

**Tecnologias:** Arduino, C/C++, RFID e servo motor.

[Repositório do projeto](https://github.com/Famontegro/ProjetoNFC)

### 02. Calculadora Científica em C

Projeto pessoal desenvolvido em linguagem C, com 44 menus, 107 operações diferentes e 3.069 linhas de código. Utiliza apenas a biblioteca `stdio.h`, explorando lógica de programação e operações matemáticas.

**Tecnologias:** C e lógica de programação.

[Repositório do projeto](https://github.com/Famontegro/Calculadora-Cientifica-Avancada-em-C-usando-uma-Biblioteca)

### 03. Projeto de Prevenção de Incêndios

Projeto acadêmico desenvolvido na USF, com foco na utilização de tecnologia para identificar e prevenir situações de risco.

**Tecnologias:** Sensores, automação e eletrônica.

*Projeto em desenvolvimento.*

## Como executar

1. Faça o clone do repositório:

```bash

```

2. Entre na pasta do projeto:

```bash
cd NOME-DO-REPOSITORIO
```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um ambiente de desenvolvimento para visualizar o site.
